<threat_model>
## Assets

- Frozen repository/PR/pin/tree identities and authoritative Git proof.
- Exact raw bytes, derived lineage, content manifest, manifest digest, and logical root.
- Immutable accepted generation namespace and rejected-attempt evidence.
- Human source-publication decision.

## Trust Boundaries

| Boundary | Untrusted input crossing it |
|---|---|
| canonical upstream PR ref → disposable Git repository | mutable/force-pushed head and network-delivered Git objects |
| reviewer request inventory → Git object extraction | paths, roles, transforms, duplicate/alias relationships |
| staging tree → accepted namespace | concurrent publishers, interrupted writes, filesystem semantics |

## Attacker capabilities

- Present an existing but PR-unrelated commit or move/force-push the PR head.
- Request escaping/aliased paths or substitute normalized/derived bytes for raw authority.
- Race publication, interrupt writes, or pre-create a target generation.

## Abuse cases and mitigations

| Threat ID | STRIDE | Component | Severity | Disposition | Mitigation and verification |
|---|---|---|---|---|---|
| T-01-08 | Spoofing | PR identity | high | mitigate | local commit/tree/type and equality-or-ancestry proof; unrelated-commit fixture plus real #2192 rejection |
| T-01-09 | Tampering | raw/derived custody | high | mitigate | exact object bytes, independent raw digest/length, explicit transform lineage; CRLF/NFC negative fixtures |
| T-01-10 | Tampering / Elevation | inventory paths | high | mitigate | unique relative POSIX identities, lstat containment, alias/collision rejection; adversarial inventory tests |
| T-01-11 | Tampering / Repudiation | accepted publication | high | mitigate | validated sibling staging, non-replacing atomic rename, immutable target, concurrency/interruption tests |
| T-01-12 | Repudiation | final snapshot-manifest binding | high | mitigate | canonical self-digest plus core/root recomputation and top-level/per-snapshot tamper tests |
| T-01-13 | Denial of Service | construction network | low | accept | network loss may block refresh but cannot weaken or invalidate already accepted offline generations |

ASVS target is L1-equivalent. Every high-severity threat is mitigated and blocks publication
until its tests pass. No package is installed. Generic path traversal and supply-chain
concerns are security canon; the plan applies their controls and leaves independent audit
to `$gsd-secure-phase` rather than minting bespoke prohibitions.
</threat_model>
