<threat_model>
## Assets

- Accepted generation identity and bundle-local verification code.
- Immutable phase-start baseline and complete worktree attribution.
- Authoritative integrity JSON, receipt digest, and reviewer decision.
- Derived Markdown presentation.

## Trust Boundaries

| Boundary | Untrusted input crossing it |
|---|---|
| copied bundle → offline verifier | altered bytes, paths, modes, manifests, identity envelopes |
| repository worktree → boundary receipt | pre-existing and later staged/tracked/untracked states |
| canonical JSON → Markdown renderer | structured fields that must not trigger independent lookup/calculation |
| automated receipt → human decision | misleading presentation or attempted waiver of a failed gate |

## Attacker capabilities

- Alter bundle bytes/identity, add a link, remove a manifest entry, or present rejected
  evidence as accepted.
- Hide or reattribute a worktree change.
- Make Markdown disagree with JSON or use reviewer approval to bypass a machine failure.

## Abuse cases and mitigations

| Threat ID | STRIDE | Component | Severity | Disposition | Mitigation and verification |
|---|---|---|---|---|---|
| T-01-14 | Spoofing / Tampering | offline verifier and snapshot binding | high | mitigate | accepted-state gate, per-snapshot generation/root/manifest recomputation, binding-tamper fixtures, and copied-directory no-Git/network test |
| T-01-15 | Elevation / Disclosure | bundle filesystem | high | mitigate | Plan 01 lstat/containment policy runs before every read; tampered link/special/path fixtures reject |
| T-01-16 | Tampering / Repudiation | integrity JSON | high | mitigate | versioned canonical projection and non-cyclic receipt self-hash; golden/determinism tests |
| T-01-17 | Tampering / Repudiation | Markdown | medium | mitigate | JSON-only renderer, no source-module imports, byte-identical rerender test, package-incomplete nonzero on failure |
| T-01-18 | Tampering | reviewer override | high | mitigate | finalize command requires automated pass eligibility before approval and preserves all blocking diagnostics |
| T-01-19 | Denial of Service | Markdown generation | low | accept | reviewer package may be incomplete, but valid JSON authority remains recoverable and unchanged |

ASVS target is L1-equivalent. Every high-severity threat has a concrete blocking mitigation
and automated test. No package manager or external API is present. Generic path and
supply-chain items remain security-hook canon, not bespoke prohibitions.
</threat_model>
