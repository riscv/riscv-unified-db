<threat_model>
## Assets

- Canonical environment decision and its SHA-256.
- Non-canonical operational audit evidence.
- Frozen fallback ceiling and first-trigger incident time.
- Root dependency and UDB toolchain state that must remain untouched.

## Trust Boundaries

| Boundary | Untrusted input crossing it |
|---|---|
| process/tool observations → canonical decision | platform-specific versions, paths, errors, host/user data |
| operational attempts → incident policy | retries, waits, alternate setup actions, mutable timestamps |
| canonical decision → audit receipt | digest reference and sanitized operational context |

## Attacker capabilities

- Inject machine-local or credential-bearing strings into tool output.
- Reset or pause the incident clock by changing setup approaches.
- Mislabel standalone-first as a fallback or claim full UDB setup was attempted.

## Abuse cases and mitigations

| Threat ID | STRIDE | Component | Severity | Disposition | Mitigation and verification |
|---|---|---|---|---|---|
| T-01-04 | Tampering / Repudiation | canonical environment decision | high | mitigate | stable field allowlist and deterministic canonical tests exclude audit-only values |
| T-01-05 | Tampering | incident clock | high | mitigate | immutable first trigger plus injected-clock retry/wait tests prove no reset/pause |
| T-01-06 | Information Disclosure | environment audit | medium | mitigate | explicit sanitization and credential/path fixtures before audit write |
| T-01-07 | Denial of Service | unexpected dependency | low | accept | cumulative 90-minute ceiling bounds expansion and preserves a documented workaround/Red outcome |

ASVS target is L1-equivalent. Every high-severity result blocks environment acceptance.
No package legitimacy gate or external API coverage artifact is required because this plan
installs no package and introduces no endpoint/SDK.
</threat_model>
