## Trust Boundaries

| Boundary | Description |
|---|---|
| Filesystem namespace to held descriptors | An attacker or concurrent process can replace roots, directories, and leaves between observations. |
| Accepted bundle to standalone verifier | Embedded code is executable and currently precedes repository modules on `sys.path`. |
| CLI receipt to downstream consumer | A receipt assembled by reopening paths could attest to different bytes than those verified. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-09-01 | Tampering | Root/intermediate/leaf traversal | high | mitigate | Hold dirfds for the complete operation, no-follow every hop, compare stat/fstat identity, and use nonblocking final open. |
| T-02-09-02 | Denial of Service | FIFO replacement | high | mitigate | Require `O_NONBLOCK`, reject non-regular fstat mode, and prove bounded completion. |
| T-02-09-03 | Spoofing | Embedded verifier | high | mitigate | Future successor embeds the fixed modules; immutable vulnerable v2 is never treated as active after successor acceptance. |
| T-02-09-04 | Repudiation | Expected-red baseline | medium | mitigate | Exact binary-safe oracle records method IDs, counts, categories, and normalized diagnostics. |
| T-02-09-SC | Tampering | Dependency supply chain | low | accept | No package installation or dependency change is authorized; standard library only. |
</threat_model>
